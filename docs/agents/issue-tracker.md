# Issue Tracker: GitHub

This repo tracks issues in GitHub Issues (`quality-gates/messharp`).

## For skills that read/write issues

- Create issues via the GitHub MCP tools (or `gh issue create` if working from a CLI context).
- Search existing issues (`search_issues` / `list_issues`) before creating new ones, to avoid duplicates.
- Set `state_reason` when closing issues.
- Check `list_issue_types` for org-level issue types before creating one, if applicable.

## PRs as a request surface

Off. Pull requests are not treated as an issue-tracker input for triage or ticketing skills.
